# Public release notes

## RaccoonOS 6.0.0 Public — publication testing

- Familiar desktop shell with Start menu, taskbar, tray, files, settings, notifications, and system sounds.
- A separate Public build profile that excludes Personal configuration, accounts, and developer material.
- A separately signed Public update repository for RaccoonOS packages, alongside Debian's signed repositories.
- Tray bug reporting with a complete preview and explicit approval before sending to the private owner inbox.
- Installation instructions, FAQ, and detailed help on the public website.

An ISO and final checksum will be linked only after the build and installation acceptance checks pass.
