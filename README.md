# RaccoonOS Public releases

This is the public download and issue hub for **RaccoonOS Public**, a Debian-based desktop operating system. The development source repository is private. This repository contains release files, checksums, licensing, notices, and public issue forms; it is not a source-code mirror.

The current download and installation instructions are at [RaccoonOS Downloads](https://chan-dashboard-six.vercel.app/download) and [Install](https://chan-dashboard-six.vercel.app/install). Only use an ISO listed there with its complete SHA-256 checksum. If no ISO is listed yet, publication testing is still underway.

RaccoonOS Public shell updates come from the [separate signed Public update repository](https://jonaskuusela393-ctrl.github.io/raccoonos-public-updates/). Debian packages continue to come from Debian's signed repositories. An update is not remote access to your computer; you review and install it locally.

For bugs, use the [issue form](https://github.com/jonaskuusela393-ctrl/raccoonos-public-releases/issues/new/choose), or the Report a Problem icon in the RaccoonOS tray to preview and send a private report. Never post passwords, tokens, recovery keys, serial numbers, or private documents. For security reports, use the private contact route at [RaccoonOS security](https://chan-dashboard-six.vercel.app/security).

RaccoonOS-owned work is covered by [LICENSE](LICENSE), and bundled third-party works retain their own licenses as detailed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
